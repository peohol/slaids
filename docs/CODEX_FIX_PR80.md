# Midlertidig reparasjonsnotat for PR #80

Dette dokumentet er kun et implementasjonsnotat for Codex og skal slettes i samme reparasjonscommit.

Reparer alle punktene i top-level-kommentaren «Tilbakemelding fra ChatGPT» på PR #80, inkludert Codex sitt eget inline-funn. Konkret:

1. Flytt den normative rasterarbeidsflyten til én navngitt konstant i `src/agent/design.ts` (f.eks. `RASTER_WORKFLOW_RULE`). Den skal slå fast at Slaids-API-et bevisst ikke genererer rasterbilder, at agenten aldri skal undersøke om Slaids/klienten «har en bildegenerator» før bildeplanlegging, og at bildesone + bildeplan + felles bildekontekst + generert brief alltid er standardflyten for rasterbilder, ikke fallback/nødløsning.
2. Fjern availability/fallback-grenene fra `IMAGE_USAGE_RULE`, `IMAGE_POLICY_SUMMARY` og `RASTER_POLICY`: ingen «mangler du rastergenerator», «har du ingen», eller positiv instruks om å melde en manglende generator som begrensning. Behold forbudet mot hjemmelaget/rasterisert SVG som erstatning.
3. `src/server/mcp/instructions.ts` skal importere og bruke den nye konstante regelen nøyaktig én gang. Fjern hardkodede duplikater og unngå parallelle normative formuleringer. Den samme regelen skal også beskrive klient-handoff: når vertsklienten allerede har innebygd bildegenerering og brukeren har bedt om generering, hent Slaids sin ferdige bildebrief og send den direkte videre i samme samtale uten at brukeren må kopiere/lime. Hvis vertsklienten ikke kan gjøre dette, er briefen fortsatt normal leveranse til stedet bildene produseres; det er ikke en fallback.
4. Oppdater eksisterende tester til den nye kontrakten i stedet for å bevare gamle regexer med misvisende formuleringer. Spesielt `src/server/mcp/instructions.test.ts` og `src/server/mcp/visualPlanningInstructions.test.ts`. Legg inn regresjonsdekning for at agentflaten ikke inneholder availability-grener som «mangler du en rastergenerator» / «har du ingen [bildegenerator]», at rasterflyten omtales som standard, at direkte klient-handoff finnes, og at den nye normative konstanten forekommer nøyaktig én gang på agentflaten.
5. Samordne `docs/AGENT_PRESENTATION_DESIGN.md`, `README.md` og relevant del av `IMPLEMENTATION_PLAN.md`. Fjern beskrivelser av «manglende bildegenerator» som særtilfelle og av at brukeren nødvendigvis må kopiere briefen til en separat samtale. Beskriv standardflyten og ChatGPT-handoff korrekt. Manuell kopiering og bildedeponering skal fortsatt beskrives som en gyldig filoverføringsvei når direkte filbro mangler, ikke som nød/fallback.
6. Slett `docs/IMAGE_GENERATION_HANDOFF.md`; innholdet skal være foldet inn i de eksisterende autoritative dokumentene. Slett også dette midlertidige `docs/CODEX_FIX_PR80.md` før commit.
7. Kjør `npm test`, `npm run typecheck`, `npm run build` og gjerne `npm run lint`. Ikke skjul svikt ved å svekke tester. Rett eventuelle nye feil.
8. Commit alle rettelser direkte til eksisterende PR-branch `docs/image-brief-default-workflow`.
